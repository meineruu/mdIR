# MedIR API

Backend FastAPI untuk demo MedIR (retrieval biomedis pada NFCorpus, model Final stacking).

- `GET /api/health`
- `GET /api/queries/test`
- `POST /api/search`
- `GET /api/summary`

Server butuh sekitar satu menit setelah menyala untuk memuat indeks dan model.
